### WEBMCP 
Webmcp standardizes browser <-> website elicitation. Rather than scanning the website - website and browser can talk to each other. 

1. **Visual Scraping Builder** — Point-and-click tool for building web scraping workflows. Users select elements on a live webpage (via the browser/CEF layer) to configure extraction nodes. The builder produces a reusable scraping definition that can be plugged into agent workflows as a data source.
